# DefyX

DefyX is a web application designed for shared challenges, providing users with a platform to explore, participate in, and invite others to various challenges. The application is built using HTML, CSS, and vanilla JavaScript, following a mobile-first approach.

## Project Structure

```
DefyX
├── index.html       # Main structure of the application
├── style.css        # Visual design and styles
├── script.js        # JavaScript for interactions
└── README.md        # Project documentation
```

## Features

- **Welcome Page**: Users can select between "Modo Familiar" and "Modo +18 (requiere verificación)".
- **Exploration Page**: A public list of challenges displayed as cards with details and a "Ver más" button.
- **Challenge Detail Page**: Displays an image, description, estimated value, and options to invite someone or unlock the challenge for a fee.
- **Invitation Page**: A simple form to invite others, with an option to enter a payment amount for paid challenges.
- **Evidence Upload Page**: Allows users to upload images or videos, add comments, and mark challenges as completed.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `index.html` file in a web browser to view the application.
3. Ensure that JavaScript is enabled in your browser for full functionality.

## Running the Application

To run the application locally, simply open the `index.html` file in your preferred web browser. The application is designed to be responsive and should work well on both mobile and desktop devices.

## Technologies Used

- HTML5 for semantic structure
- CSS3 for styling with a mobile-first approach
- Vanilla JavaScript for interactivity
